# SkyAutoMusic 自动弹琴

读取 JSON 乐谱，自动模拟按键演奏《Sky 光遇》乐器的小工具，带图形界面。

## 功能
- 自动扫描 `Sheet Music` 文件夹中的 JSON 乐谱
- 支持搜索、收藏、全部/收藏分页
- 同一时刻的多个音符可同时按下
- 全局热键：`F5` 开始，`F7` 停止
- 自动检测并激活 Sky / 光遇 游戏窗口
- 自动保存窗口位置和收藏记录

## 安装
需要 Windows 和 Python 3.8+：

```bash
pip install pyautogui keyboard psutil pywin32
```

## 使用
1. 把 JSON 乐谱放入 `Sheet Music` 文件夹。
2. 运行程序：

   ```bash
   python play_music_gui.py
   ```

3. 在左侧列表选择乐谱，点击“开始演奏”或按 `F5`。
4. 按 `F7` 停止；右键乐谱可收藏。
5. 切换到“收藏曲谱”分页只显示已收藏乐谱。

> 演奏前请先打开游戏，并保持游戏窗口在前台。

## 乐谱格式
```json
[
  {
    "name": "曲名",
    "author": "作者",
    "transcribedBy": "制谱人",
    "bpm": 120,
    "songNotes": [
      {"time": 948, "key": "1Key0"},
      {"time": 948, "key": "1Key2"}
    ]
  }
]
```

- 顶层必须是列表，第一个元素需包含 `songNotes`。
- `time` 单位为毫秒；同一 `time` 下的多个 `key` 会同时按下。
- `key` 取值：`1Key0`～`1Key14`、`2Key0`～`2Key14`，对应 `y u i o p h j k l ; n m , . /`。

## 注意事项
- 仅支持 Windows；热键注册失败时请以管理员身份运行。
- 演奏期间不要操作键盘或切换窗口，否则按键可能发到错误位置。
- 若 `F5` / `F7` 被其他软件占用，需修改代码中的默认热键。
- 当前版本只读取 `bpm`，不会据此调整速度；总时长固定显示 `0:00`。
- 点击“停止”后再次开始会从头播放。
- 单文件打包运行时，`config.json` 和 `favorites.json` 可能无法持久保存。

## 常见问题
- **列表里没有乐谱？** 确认文件在 `Sheet Music` 文件夹内且扩展名为 `.json`。
- **热键无效？** 以管理员身份运行，或修改代码中的默认热键。
- **按键不对？** 修改代码中的 `note_to_key` 映射表。
